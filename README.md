# TemplateKaizer — конструктор мессенджера

Это не готовый мессенджер «из коробки», а **база**, чтобы ты быстро собрал свой. Автор: KaizerDev.  
Лицензия: MIT — можно свободно модифицировать, делать свои версии, добавлять темы и функции.

## Что уже работает

- Отправка и получение сообщений в реальном времени (WebSocket).
- История сообщений хранится в SQLite.
- Статусы доставки (`delivered`).
- Простая кастомизация тем (CSS) и логики (JS/Node).

## Как запустить локально (для теста)

1. `npm init -y` (если ещё нет package.json)
2. `npm install`
3. `npm start` или `node server/index.js`
4. Открой `http://localhost:3000`

## Как сделать, чтобы чатились из разных сетей (не только в одной Wi‑Fi)

Чтобы люди могли переписываться из разных мест, нужен **свой сервер** с публичным адресом.

### Вариант 1: VPS (самый правильный для своего мессенджера)
1. Берёшь VPS (Ubuntu) у любого хостинга (Timeweb, Beget, Reg.ru, Selectel и т.п.).
2. Ставишь туда Node.js.
3. Загружаешь проект, запускаешь `node server/index.js`.
4. Настраиваешь Nginx как обратный прокси для WebSocket (обязательно, иначе WSS не заработает).
5. Получаешь домен или IP и открываешь ссылку — чатятся все, кто на неё зашёл.

### Вариант 2: Свой компьютер/ноутбук (для теста и своих)
1. Поднимаешь сервер на своём ПК/ноутбуке.
2. Настраиваешь проброс портов на роутере (Port Forwarding) для порта 3000.
3. Используешь DDNS (например, No-IP), чтобы получить постоянный адрес.
4. Открываешь ссылку извне — чатятся те, у кого есть адрес.

> ⚠️ Важно про WSS: если используешь HTTPS/домен, в коде уже есть автоопределение `wss://`.

## Куда добавлять своё (полная кастомизация)

- `public/style.css` — меняй цвета, делай тёмную/синюю тему, меняй шрифты.
- `server/index.js` — добавляй файлы, голосовые, статусы прочтения, комнаты чатов.
- `migrations/` — создавай новые таблицы (пользователи, диалоги, медиа).
- `public/script.js` — меняй логику отображения, добавляй эмодзи, автопрокрутку и т.д.
